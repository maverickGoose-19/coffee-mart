
# Review Design Document

This is the original Figma-exported code bundle for the marketplace website.

- https://www.figma.com/design/0HD5jM3Sz0rprI3yVjGBdX/Review-design-document

## Design Notes

The live local implementation was adapted from this bundle and extended to cover product gaps that were still missing in the original export:

- buyer preference onboarding
- explainable recommendation rail in catalog
- "why this matches you" on coffee detail
- similar lots block
- recommendation analytics in admin
- live supplier onboarding submission into Supabase

## Live Prototype

The runnable local prototype lives in:

- `product/web-app`

It uses Python instead of the original Vite toolchain because Node is not installed in this environment.
